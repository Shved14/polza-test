# Email Outreach Personalization Tool

Инструмент автоматической персонализации компаний для холодного email-аутрича.

## Описание

Программа анализирует веб-сайты компаний и генерирует короткие персонализации для холодных email-рассылок на основе информации, найденной на сайтах.

## Стек технологий

- **Node.js** - runtime среда
- **TypeScript** - типизация
- **npm** - менеджер пакетов
- **OpenAI API** - генерация персонализаций
- **Axios** - HTTP запросы
- **Cheerio** - парсинг HTML
- **csv-parser** - чтение CSV
- **csv-writer** - запись CSV

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:

```bash
npm install
```

3. Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

4. Отредактируйте `.env` и добавьте ваш API ключ OpenAI:

```
OPENAI_API_KEY=your_openai_api_key_here
MODEL=gpt-3.5-turbo
```

## Формат входного CSV файла

Создайте файл `input/companies.csv` со следующими колонками:

```csv
Компания,Сайт,Email
Пример Компания,https://example.com,contact@example.com
Тест ООО,https://test.ru,info@test.ru
```

**Важно:** Колонки должны называться точно так же: `Компания`, `Сайт`, `Email`.

```csv

Тест ООО,https://test.ru,info@test.ru,Не удалось найти достоверную информацию для персонализации.
```

## Как это работает

1. Программа читает CSV файл из `input/companies.csv`
2. Для каждой компании:
   - Открывает сайт и получает HTML главной страницы
   - Ищет страницу "О компании" и получает её текст
   - Ищет раздел "Новости" или "Блог" и получает текст последних новостей
   - Очищает HTML от лишнего мусора (скрипты, стили, комментарии)
   - Ограничивает размер текста перед отправкой в OpenAI
   - Отправляет информацию в OpenAI API
   - Получает короткую персонализацию (максимум 40 слов, 2 предложения)
3. Записывает результат в `output/result.csv`

## Обработка ошибок

Программа обрабатывает следующие ошибки:
- Некорректный URL
- Отсутствие сайта
- Таймаут соединения
- Ошибка 404
- Ошибки OpenAI API
- Пустой HTML
- Ошибки сети

Если одна компания не обработалась, программа продолжает работу с остальными.

## Требования к персонализации

- Используется только информация, найденная на сайте
- Не придумываются факты
- Нет галлюцинаций
- Если информации недостаточно — возвращается текст: "Не удалось найти достоверную информацию для персонализации."
- Максимальная длина — 40 слов
- Максимум 2 предложения
