# Инструмент персонализации для email-аутрича

Инструмент автоматической персонализации компаний для холодного email-аутрича.

## Описание

Программа анализирует веб-сайты компаний и генерирует короткие персонализации для холодных email-рассылок на основе информации, найденной на сайтах.

## Технологический стек

- **Node.js** - runtime среда
- **TypeScript** - типобезопасность
- **npm** - менеджер пакетов
- **Google Gemini API** - генерация персонализаций
- **Axios** - HTTP запросы
- **Cheerio** - парсинг HTML
- **csv-parser** - чтение CSV
- **csv-writer** - запись CSV
- **p-limit** - контроль параллелизма
- **cli-progress** - индикатор прогресса
- **yargs** - аргументы CLI
- **zod** - валидация данных
- **ipaddr.js** - валидация IP-адресов

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:

```bash
npm install
```

3. Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

4. Отредактируйте `.env` и добавьте ваш API ключ Gemini:

```
GEMINI_API_KEY=your_gemini_api_key_here
MODEL=gemini-pro-latest
LLM_MAX_TOKENS=200
LLM_TEMPERATURE=0.7
SCRAPING_TIMEOUT=30000
SCRAPING_MAX_RETRIES=3
SCRAPING_RETRY_DELAY=1000
SCRAPING_MAX_TEXT_LENGTH=6000
SCRAPING_CONCURRENCY=3
```

## Конфигурация

Переменные окружения:

- `GEMINI_API_KEY` - Ваш API ключ Gemini (обязательно)
- `MODEL` - Модель Gemini (по умолчанию: gemini-pro-latest)
- `LLM_MAX_TOKENS` - Максимальное количество токенов ответа (по умолчанию: 200)
- `LLM_TEMPERATURE` - Температура генерации (по умолчанию: 0.7)
- `SCRAPING_TIMEOUT` - Таймаут запроса в мс (по умолчанию: 30000)
- `SCRAPING_MAX_RETRIES` - Максимальное количество попыток (по умолчанию: 3)
- `SCRAPING_RETRY_DELAY` - Начальная задержка повтора в мс (по умолчанию: 1000)
- `SCRAPING_MAX_TEXT_LENGTH` - Максимальная длина текста перед отправкой в AI (по умолчанию: 6000)
- `SCRAPING_CONCURRENCY` - Количество параллельных запросов (по умолчанию: 3)

## Формат входного CSV файла

Создайте `input/companies.csv` со следующими колонками:

```csv
Компания,Сайт,Email
Пример Компания,https://example.com,contact@example.com
Тест ООО,https://test.ru,info@test.ru
```

**Важно:** Колонки должны называться точно: `Компания`, `Сайт`, `Email`.

```csv
Тест ООО,https://test.ru,info@test.ru,Unable to find reliable information for personalization.
```

## Как это работает

1. Программа читает CSV файл из `input/companies.csv`
2. Для каждой компании:
   - Получает HTML сайта
   - Находит страницу "О компании" и извлекает текст
   - Находит раздел "Новости" или "Блог" и извлекает текст
   - Очищает HTML от скриптов, стилей, комментариев, рекламы
   - Обрезает текст до оптимального размера для AI
   - Отправляет информацию в Gemini API
   - Получает короткую персонализацию (максимум 40 слов, 2 предложения)
3. Записывает результаты в `output/result.csv`

## Возможности

- **Параллельная обработка**: Обрабатывает несколько компаний одновременно с настраиваемым лимитом
- **Retry логика**: Экспоненциальный backoff для временных ошибок
- **Rate limiting**: Встроенный rate limiting для Gemini API
- **SSRF защита**: Валидация URL для предотвращения SSRF атак
- **Валидация входных данных**: Проверка CSV данных с помощью Zod схем
- **Прогресс-бар**: Визуальный индикатор прогресса с ETA
- **Graceful shutdown**: Обработка сигналов SIGINT/SIGTERM
- **Настраиваемость**: Все параметры настраиваются через переменные окружения
- **Обработка ошибок**: Комплексная обработка ошибок, продолжение работы при индивидуальных сбоях
- **Архитектура провайдеров**: Интерфейс LLMProvider позволяет легко добавлять другие LLM (OpenAI, Claude, DeepSeek)

## Обработка ошибок

Программа обрабатывает:
- Некорректные URL
- Отсутствующие сайты
- Таймауты соединения
- Ошибки 404
- Ошибки Gemini API (включая rate limits)
- Пустой HTML
- Сетевые ошибки
- Некорректные данные CSV

Если одна компания не обработалась, программа продолжает работу с остальными.

## Требования к персонализации

- Используется только информация, найденная на сайте
- Не придумываются факты и нет галлюцинаций
- Если информации недостаточно, возвращается: "Unable to find reliable information for personalization."
- Максимум 40 слов
- Максимум 2 предложения

## Безопасность

- Валидация URL предотвращает SSRF атаки

- Localhost блокируется
- Metadata endpoints блокируются
- Разрешены только протоколы HTTP/HTTPS
